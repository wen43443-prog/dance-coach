# 舞帧 · 舞蹈慢动作拆解

把一段舞蹈视频变成"逐帧教练"：慢放、逐帧拆解、把关键画面定格成一拍并写上口令，语音读口令带你练。**手机浏览器直接用，无需安装 App。**

## 功能

- **AI 智能拆解（本地运行，不上传）**：点「🤖 AI」分析视频后可获得——
  - 🦴 **骨架叠加**：火柴人骨架贴合人物，播放/逐帧/拖动全程显示，动作结构一目了然
  - 📐 **关节角度**：肩、肘、膝角度实时标注，"抬到多少度"不再靠感觉
  - ⚡ **自动关键帧**：按动作幅度自动找出变化最大的瞬间，一键生成关键帧草稿，拆舞从半小时变几分钟
  - 〰️ **运动轨迹**：手脚尖 2 秒残影轨迹，划圆还是直线一眼看清
  - ⚖️ **左右对称提示**：实时对比左右手臂/腿的抬升差，自己看不见的不对称它告诉你
  - 首次使用需下载模型（约 12MB，已自托管在你的网址下，国内直连），之后**离线可用**
- **教练级训练系统**：
  - 🎤 **真人语音口令**：每拍可以录自己的声音，领练时用你的声音代替机械 TTS
  - 🎙 **领练三种模式**：标准领练 / 渐进提速（0.25×→1× 自动爬速，每档可练多遍）/ 随机抽考
  - ⏱ **每拍倒计时**：3·2·1·走！视听双通道
  - ✓ **掌握度管理**：每拍标记"已掌握"，可只练没掌握的
  - 👻 **上一帧残影**：洋葱皮效果，动作方向直接画在画面里
  - 🎯 **帧级 A-B 循环**：A/B 点自动对齐帧网格，循环精确到帧
- **AI 深度功能**：
  - 🤸 **跟练对比打分**：打开手机摄像头，你的骨架和教学视频骨架实时对比，按关节角度偏差打分（0-100），指出最需改进的部位
  - 🎵 **音乐节拍分析**：自动检测 BPM 并在时间轴上显示节拍刻度，关键帧一键对齐节拍
  - 📤 **教学长图导出**：关键帧+口令合成一张长图，可直接分享（支持系统分享面板）
- **导入视频**：从手机相册/文件选择视频（支持 mp4 / mov / webm 等），也可在电脑上拖拽进来
- **慢速播放**：0.1× ~ 1× 无级变速，音调不变（变速不变调）
- **逐帧步进**：上一帧 / 下一帧按钮，或点视频左右两侧；帧率自动检测，也可手动设定
- **镜像模式**：左右翻转画面，像照镜子一样跟学
- **关键帧拆解**：暂停在要记住的画面 → 「📸 拆解此帧」→ 自动截图 + 编拍号，可写动作口令
- **语音教导**：播放走到某一拍时，自动朗读该拍口令（手机系统中文语音）
- **领练模式**：自动逐拍讲解 + 慢速演示，循环带你过完全部关键帧，屏幕保持常亮
- **A-B 循环**：设定起点终点，反复磨一个小节
- **本地保存**：视频和关键帧存在手机浏览器本地（IndexedDB），下次打开继续用；不上传任何数据

## 使用流程建议

> 文件夹里附了一个测试视频 `testdata/dance-test.mp4`（8 秒彩条），可先拿它熟悉流程。

1. 导入视频 → 开 0.25× 慢放看一遍全貌
2. 遇到关键造型/发力点就暂停，点「📸 拆解此帧」，写一句口令（如"重心移左脚，右手划圆"）
3. 点「🎙 领练模式」，听语音逐拍带你过动作
4. 难点小节用「设 A / 设 B」循环慢磨

## 常见问题

- **逐帧不准 / 一跳跳两帧**：设置里手动改"帧率"（常见 30 或 60，高帧率拍摄的视频是 60/120）
- **语音没声音**：需要手机系统带中文语音包（iPhone: 设置-辅助功能-朗读内容；安卓: 系统设置-文字转语音）；首次朗读需先点一下屏幕
- **iOS 低倍速卡顿**：iOS 对 0.1× 支持不佳，建议用 0.25×；逐帧功能不受影响
- **换手机数据不在**：数据只存在本机浏览器，换设备需重新导入

## 技术说明

纯前端单文件应用（`index.html`），无框架、无构建、无后端：

- 逐帧：`requestVideoFrameCallback` 精确到显示帧（前进行用"播一帧即暂停"保证准确）
- 语音：Web Speech API（`speechSynthesis`）中文 TTS
- 存储：IndexedDB 保存视频 Blob 与关键帧；设置存 localStorage
- PWA：manifest + Service Worker，https/localhost 下可离线、可安装
